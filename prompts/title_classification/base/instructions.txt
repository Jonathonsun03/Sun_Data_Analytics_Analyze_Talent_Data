Classify each YouTube title record into the JSON schema.

Rules:
1. Return JSON only. No markdown, comments, or extra keys.
2. Return one item for every input record and preserve the same `video_id`.
3. Confidence must be between 0 and 1.
4. Use only enum values listed in the schema.
5. Keep `tags` concise, specific, and bounded by schema limits.
6. Apply definitions jointly in one pass; categories may co-occur when title evidence supports it.
7. Use conservative confidence when wording is ambiguous, ironic, or meme-like.
8. Extract references:
   - If topic = gaming, set `primary_reference` to the primary game/IP title when identifiable.
   - If topic = music, set `primary_reference` to the primary song title when identifiable.
   - Fill `referenced_entities` with up to 5 key game/song references found in the title.
   - If no clear reference exists, set `primary_reference` to an empty string and keep `referenced_entities` empty.
